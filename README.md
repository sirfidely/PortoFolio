# Portfolio — Fidel Mondésir N'zoué

Portfolio de Fidel Mondésir N'zoué, Chief Product Officer et co-fondateur de [GeniusPay](https://geniuspay.ci).

Le site tient dans un seul fichier, `index.html` (HTML et CSS, sans dépendance ni étape de build).

## Voir le site en local

Ouvrir `index.html` dans un navigateur.

## Mettre le site en ligne avec GitHub Pages

1. Dans le dépôt, ouvrir **Settings → Pages**.
2. Sous **Build and deployment**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. Enregistrer. Le site sera publié à l'adresse `https://sirfidely.github.io/PortoFolio/`.
